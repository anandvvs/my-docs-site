# Second Post: Building a Docs-as-Code Workflow

Date: 2026-05-08

This post explains how a Docs-as-Code workflow works using MkDocs, Markdown, and GitHub.

## What is Docs-as-Code?

Docs-as-Code means treating documentation like software code:
- Written in Markdown
- Stored in Git repositories
- Reviewed via Git workflows
- Published through automated builds

## Why it matters

- Keeps documentation version-controlled
- Enables collaboration across teams
- Ensures consistency between code and docs
- Supports automation and CI/CD pipelines

## Tools used

- Markdown for writing content
- MkDocs for site generation
- GitHub for version control and hosting

## Key takeaway

Documentation becomes part of the engineering lifecycle, not an afterthought.
